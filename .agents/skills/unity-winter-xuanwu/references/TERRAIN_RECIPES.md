# Рецепты рельефа

1. Скопируй сцену и данные. Измерь контроллер, радиус, высоту, stepOffset, slopeLimit, roll distance и camera boom. Сохрани точки маршрута в world coordinates. Ширина = минимум 2*radius + запас для движения и камеры; 3–5 м только стартовая гипотеза. Продольный уклон целиться на 5–20°, не превышать измеренный лимит с запасом 5°; поперечный уклон 0–8° на обычном пути, у обрыва тестировать вручную. Длина roll + тормозной запас должна помещаться на безопасном участке.
2. Terrain: одна компактная сетка/тайлы, начни 513 или 1025; шаг heightmap = размер/(res−1), около 0.25–0.5 м для игровой зоны как стартовый ориентир. Пол в пределах halfWidth; smoothstep к внешнему рельефу на shoulder. Точки заранее сгладить, не склеивать самопересекающиеся части маршрута; в `protectedAreas` отметить все расщелины и запрещённые зоны. `TerrainPathBuilder` не создаёт пропасти и не строит потолки: отдельные cliff mesh и Terrain holes по необходимости, проверить физику. Для резких краёв использовать mesh с чистым коллайдером, не маскировать зияние белой плоскостью.
3. Основные стены: 3–5 prefab, крупный наклонный пласт + меньший стык в теле стены. Поворот вокруг вертикальной оси и умеренное равномерное изменение масштаба; не растягивать текстуру. Видимые тыльные стороны закрыть естественными массами. Не отключать backface culling глобально.
4. Сугроб: terrain макроформа; у основания стены положить одну низкую mesh-форму, частично утопленную в землю (без z-fighting). Сверить normals, texel density, цвет. На верхней полке отдельная снежная шапка. На игровом полу единственный непрерывный collider, не многослойный.
5. Панцирь: отдельный меш с гладким выпуклым силуэтом, пологим подъёмом, ободом; local pivot и anchors сохранить. Collider отдельный от Terrain. Не помещать случайные камни. Для временной геометрии — утверждённый placeholder существующего размера, не менять босса.
6. Фон: 2–3 горных массива, разная глубина, лёгкие материалы, без collider, тени выключать только после проверки. `MountainBackdropBuilder` допустим только как временный невидимый/черновой прокси; видимые дальние скалы финальной сцены — готовые ассеты. Скрыть края в тумане; не позволить игроку видеть изнанку.
7. Снеговой маске: 20° чистый снег → 55° открытый камень, плюс малый шум; это стартовые параметры. Не красить весь hand-painted tile автоматически. На мешах использовать ручную маску/vertex colors и локальные caps. Shader Graph custom function опционален.
