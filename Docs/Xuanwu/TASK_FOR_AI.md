# Задание для ИИ-агента: переустановка Skill v4.4 и построение зимней локации

Тебе предоставлен ZIP `Xuanwu_Complete_v4_4_Optimization_First.zip`. В Unity-проекте уже установлен старый Skill `unity-winter-xuanwu`, а Graybox зимней локации Сюаньу уже готов. Твоя задача — самостоятельно обновить инструментарий **и после проверок сразу начать работу над локацией**. Не жди отдельной команды на построение.

1. Найди Unity-проект и старый skill. Распакуй ZIP вне Assets, изучи INSTALL_FOR_AI.md. Сделай резерв старого навыка вне активных skills, переустанови версию v4.4 в существующий путь. Сохрани пользовательские правки, настройки Unity/Meshy MCP, импортированные ассеты, .meta/GUID, рабочие конфигурации, журналы задач/кредитов и прогресс. Не создавай две активные версии и не затирай рабочие данные пустыми шаблонами. Новые поля и QA добавь неразрушающим слиянием. Проверь, что активен именно v4.4.
2. Размести документацию, каталоги, референсы и инструменты согласно INSTALL_FOR_AI.md. Проверь компиляцию Editor Tools, Python-тесты и работу MCP, не ломая проект и не запуская платные генерации при установке. Сохрани исходный статус и отчёт. Если Unity доступна, выполни smoke test на отдельной копии; если нет — сообщи блокер, не имитируй результат.
3. У тебя уже есть готовый Graybox. Используй именно его как основу: измерь существующую тропу, её расстояния, повороты, высоты, ширину и шесть зон, сохрани якоря и непрерывный подъём 5→6. Утверждённая карта ROUTE_APPROVED.png имеет приоритет. Не проектируй другой маршрут. Сохрани исходную сцену и TerrainData, работай в копии. Старые шестиугольные стены и грубые Terrain-скалы — не образец финальной формы. Полностью замени их и устаревшие коллизии природными 3D-ассетами, не накладывай текстуры на примитивы и не украшай их парой камней. Terrain — для проходимой земли, снежных склонов. Не меняй игровые механики.
4. Создай окружение по атмосфере Battlefield V — Fjell 652: совместимые угловатые скалы, тёмно-синяя порода, снег и естественные скальные границы. **Оптимизация выше красоты и микродетализации**: сохраняй крупные читаемые формы, используй наименее тяжёлые подходящие ассеты, LOD, простые коллизии и общие материалы. Прочитай OPTIMIZATION_FIRST.md и optimization-budgets.json. Сначала готовые модели из проекта/каталога, выбирай по форме; коричневый цвет можно перекрасить локально. Не импортируй все 150 ассетов.
5. Только если подходящей формы нет после поиска в библиотеке и проверки максимум двух новых кандидатов, используй Meshy MCP. Составь промпт по MESHY_PROMPT_GUIDE.md и шаблонам, укажи малый бюджет треугольников по роли, triangle topology при поддержке, дешёвый geometry-only preview без текстур. Сохрани task ID, скачай FBX, импортируй и локально оптимизируй. Не используй Ultra, платный refine/retexture/remesh, не генерируй ради цвета/красоты; максимум две попытки при конкретном дефекте формы, дорогая модель только по отдельному согласованию. Генерации только в рамках действующего явно согласованного лимита; если его нет, запроси один общий лимит при необходимости и продолжай другие зоны. Не покупай кредиты. Пока Meshy работает, занимайся независимыми участками Unity, если инструменты позволяют.
6. Проверяй фактические треугольники всех рендереров префаба по LOD, число повторов, слоты материалов, текстуры, масштаб, коллизии и силуэт. Не принимать тяжёлый меш без локальной оптимизации/согласованного исключения. Сначала создай эталонный участок 15–25 м из новой скальной геометрии, проверь clay без текстур, проходимость и производительность; затем пакетно распространи решения на оставшиеся зоны. Не меняй глобальные настройки, контроллер, камеру, бой, анимации, сложную погоду и следы. Не жертвуй проходимостью ради чисел.
7. Веди build-state.md, asset-optimization-report.json, журналы Meshy и QA01–QA25. Сними фактические baseline/after метрики Unity и контрольные кадры. Если тесты недоступны — NOT RUN, а не PASS. Работай самостоятельно и экономно; не спрашивай повторно уже известное. В финале предоставь реальную рабочую сцену, список изменений, отчёт по оптимизации, кредитам и блокерам. Не ограничивайся установкой или планом, если доступ к Unity позволяет выполнить работу.
