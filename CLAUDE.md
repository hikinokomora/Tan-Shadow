# ShadowTan

Одиночная атмосферная приключенческая игра от третьего лица о четырёх мифологических колоссах китайской традиции: Цинлун (весна), Чжуцюэ (лето), Байху (осень), Сюаньу (зима). Хаб — каменный зал «Перекрёсток».

**Вся архитектура проекта — в [ARCHITECTURE.md](ARCHITECTURE.md).** Перед любой задачей прочитай там §0 (куда вносить изменение), §2 (инварианты дизайна) и раздел затронутого модуля. Правила для нейросети — §29.

## Самое важное из инвариантов

- У героини нет прыжка и лазания; нет шкал здоровья и выносливости.
- Бег и удар несовместимы.
- Каждый колосс побеждается четырьмя засчитанными событиями (правило четырёх).
- Смерть никогда не показывается: смерть героини — чёрный экран с белой точкой, смерть колосса — белый с чёрной точкой. Под заливкой идёт загрузка.
- После победы локация становится серым грейбоксом.
- Сюжет — только слайд-шоу.
- Не выдумывать числа и механики: всё неутверждённое — поле конфига с пометкой `[Tbd]`.

## Правила работы

- **Сцены, префабы и ассеты меняй только через редактор (Unity MCP, `com.coplaydev.unity-mcp`).** Не правь YAML `.unity`, `.prefab`, `.asset` руками, если редактор открыт.
- **Если проект не компилируется,** Unity открывается в Safe Mode и MCP не работает. Сначала почини ошибки компиляции.
- **Все настраиваемые числа — в ScriptableObject**, не в коде.
- **Тайминги** считай от времени анимации или явного таймера, а не от количества кадров.
- **Пиши просто:** небольшие компоненты, понятные имена, комментарии только там, где неочевидно «почему».
- **Git + LFS** для fbx/png/psd/wav/mp3. Работа в ветках по задачам, в `main` — только собирающийся проект.
- **Перед коммитом** проект компилируется, Play Mode запускается без ошибок в консоли.
- Изменил структуру, события, ассеты или решения — обнови ARCHITECTURE.md в той же задаче.
