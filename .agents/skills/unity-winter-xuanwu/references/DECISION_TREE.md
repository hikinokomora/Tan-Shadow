# Дерево решений и лимиты
1. Не хватает формы: поиск в проекте → выбранное геологическое семейство → `catalog.py --role wall --family layered --limit 5` → проверить не более двух подходящих источников → цена/право модификации/AI scope/атрибуция → получить лучший → MaterialLab → если оба не подходят, локальная простая форма или зафиксировать blocker. Не скачивать сотни.
2. Камень тёплый: форма подходит? нет → X; да → K2, если зелень K3; neutral light review. Если после двух попыток не совпадает, заменить. Не использовать CC0 как предпочтение само по себе. Аккаунт можно получить у пользователя штатной авторизацией без передачи пароля/токена.
3. Маршрут не проходит: снять точки и коллизии, определить ground/slope/clearance/camera; править только геометрию копии. Не менять controller. Если изменение нарушит топологию, спросить пользователя.
4. Плохо выглядит: сначала silhouette → снеговой объём → свет/материал → детали; не увеличивать плотность случайных объектов.
5. Дорого: проверить profiler → убрать дальние детали или тяжёлые scans → LOD/компрессия → повторный тест. Не сокращать QA.
6. Агент: один аудит, два раунда blockout/vertical slice, один batch на зону, один final fix. После двух неудач fallback или blocker. Сохранять `build-state.md` после этапа; при возобновлении только изменённая зона. Не повторять импорт, хранить GUID/manifest/rejected IDs. Не читать весь HTML GDD/base64 или CSV; искать нужные строки. Не делать дорогостоящую погодную систему, следы, бой.

Рейтинг кандидатов: 30% форма, 25% геологическая совместимость, 20% техническая пригодность, 15% поправимость цвета, 10% стоимость получения и адаптации. Оценки 0–10 выставлять после просмотра; score = сумма(weight*score/10). >=80 предпочтительный, 65–79 резерв, ниже 65 отказ. Бесплатность/лицензия/AI — hard gate до оценки, неизвестность ≠ допуск.
