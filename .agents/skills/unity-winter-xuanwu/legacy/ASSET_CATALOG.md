# Каталог ассетов для зимней локации Сюаньу

### Политика выбора бесплатных ассетов (уточнение пользователя)
- CC0 не является обязательным условием или художественным приоритетом. Допускаются любые легально бесплатные для проекта ресурсы, включая Fab, Unity Asset Store, Sketchfab, CGTrader, BlenderKit и другие площадки, в том числе требующие аккаунта. Это список разрешённых направлений поиска, не утверждение о лицензиях конкретных ресурсов.
- Пользователь может предоставить доступ к нужному сервису. При необходимости попросить авторизоваться через штатный интерфейс или получить файл вручную; не просить пароль или токен в чате, не обходить ограничения доступа. Отсутствие текущей сессии не является причиной исключать подходящий ассет из базы.
- Критерии выбора: соответствие форме, геологии и сеттингу; возможность холодной цветокоррекции; техническая пригодность для Unity и производительность; затем затраты на получение и адаптацию. При равном качестве предпочитать уже импортированный или наиболее простой для получения ресурс независимо от CC0.
- Перед получением убедиться в нулевой цене, применимости лицензии к игре и выбранному способу обработки ИИ, разрешении модификации и использования в составе игры, учесть атрибуцию. Не использовать NoAI или неясные условия в агентском процессе без подтверждённого разрешения. Исключить платные, editorial-only и не подходящие по условиям проекта ресурсы. Бесплатная цена не равна открытой лицензии. Не оформлять платные подписки и покупки.
- В manifest фиксировать источник, лицензию, цену, условия атрибуции/AI, формат и факт получения. Не распространять исходные сторонние ассеты без соответствующего права. Для снижения расхода кредитов сохранять лимит двух новых кандидатов на роль; большой каталог — резерв, не очередь загрузки.

## 3. Конкретное решение для первого импорта
1. Если есть разрешённый Fab FBX: Large Nordic Coastal Cliff + Nordic Rock, затем Huge Snow Hill (или Snow Hill), a83ed601 и 5c0c8fc3 (или 7b805548). Ice Cliff взять максимум один для теста в A01, не обязателен. Если у выбранного ресурса AI usage не разрешён или условия неясны, отказаться от него в агентском процессе и взять другую разрешённую бесплатную альтернативу. Не утверждать, что все бесплатные карточки разрешают AI: проверено лишь выборочно.
2. Альтернатива полностью CC0: Rock Face 01 + Mountainside + один дополнительный cliff/локальный proxy; Rock 01 и Snow003/004; сугробы сформировать Terrain/простыми mesh. Можно завершить карту без Fab.
3. В отдельной тестовой сцене разместить 1 копию каждой модели. Проверь bounds (1 м = 1 unit), направление нормалей, pivot, заднюю сторону open mesh, material slots, реальную сетку/LOD, количество текстур. Сопоставь освещение. Если текстуры очень разные, выбери согласованные две, не перекрашивай всё вручную. Сохрани рабочие prefabs и общий набор материалов. 
4. Выбери один лицензированный набор, не объединяй десятки Megascans с разной фактурой. После прохождения первого участка скачивай только недостающую форму. При уже имеющейся локальной копии не качай повторно.

## 5. Расширенная библиотека вариантов (v2)

Цель — вариативность **внутри единого сеттинга**, не увеличение числа реально используемых материалов. Все дополнительные ссылки ниже найдены по публичным карточкам 24.11.2026; тип, размеры и исходные цветовые сведения берутся из описания/тегов, если они есть. Размеры Fab не являются порядком осей Unity. A — приоритетная замена в своей роли, B — запасной вариант при выполнении условий, X — исключено из агентского использования. Строки X оставлены для предотвращения повторного поиска, не как доступные ресурсы. Цвет не проверен инструментально по пикселям и не измерен в Unity. ### 5.1. Цветовые профили и фильтр сеттинга (обязательны)

| Код | Когда применять | Как адаптировать |
|---|---|---|
| K1 — холодный камень | Нейтрально-серый, графитовый или уже тёмный камень | Под общим нейтральным тестовым светом слегка убрать насыщенность, сделать холоднее; сохранить фактуру, не превращать камень в синий пластик. |
| K2 — тёплый камень | Коричневый, бежевый, рыжий, песчаный материал | **Обязательная перекраска**: сначала нейтрализовать жёлтые/красные тона, затем кривой яркости затемнить средние тона и добавить сине-серую гамму; песок в углублениях закрыть снегом либо убрать цветовой маской. Простой синий Multiply по коричневому часто даёт почти чёрный грязный результат — не применять вслепую. |
| K3 — биологический налёт | Мох, трава, лишайник, зелёные пятна | Удалить геометрию растений, убрать зелёные зоны маской или заменить материал; снежная шапка допустима на верхних поверхностях. Если растительность заметна после коррекции — исключить. |
| K4 — снег | Белый, светлый, голубоватый снег | Сохранить естественный светлый BaseColor; холодный полутон получить светом/умеренной цветовой коррекцией. Удалить жёлтую грязь, следы техники, траву; не делать поверхность глянцевой. |
| K5 — лёд | Ледяной обрыв, замёрзший уступ | Уменьшить насыщенную бирюзу, держать ледяной сине-серый оттенок. Только небольшие вставки, не стеклянные стены. |

**Рецепт K2:** не трогать исходный архив. Создать `*_Winter_Albedo` / общий вариант материала. В редакторе изображений или локальным пакетным скриптом работать в согласованном цветовом пространстве: декодировать sRGB → linear, вычислить luminance (0.2126R+0.7152G+0.0722B), смешать исходный цвет с grayscale (старт 65–90% grayscale), мягко уменьшить яркость средних тонов (стартовый множитель 0.55–0.85, если исходник светлый), умножить каналы на примерный холодный коэффициент (0.82, 0.94, 1.0) с защитой светов/теней, обратно encode sRGB. Это лишь стартовая проба; не затемнять уже тёмный камень повторно. Сравнить с образцом K1 под одинаковым светом. Насыщенность и luminance корректировать по фактической текстуре. Цвета GDD #253849 и #232D38 — визуальная цель освещённой сцены/теней, **не** буквальный RGB для всех пикселей albedo. Снег #F2F6FB/#C9D8EA. Normal, AO, height не перекрашивать; roughness/smoothness корректировать отдельно, metallic = 0. Если используется Unity Lit, roughness преобразовать в smoothness = 1 − roughness и упаковать согласно pipeline; BaseColor sRGB, data maps linear, normals импортировать как Normal map с проверкой направления Y. Не менять глобальный color grading, чтобы исправить одну модель.

**Фильтр:** выбирать одну семью трещиноватой, угловатой, массивной породы. Не смешивать резко различающиеся вулканические пористые, окатанные береговые, пустынно-полосатые и известняковые фактуры в одном видимом массиве. Названия Icelandic/Nordic не гарантируют совпадение текстур; сравнивать масштаб слоёв, направление плоскостей, степень эрозии и цвет. Ни одного здания, растения, рукотворной поверхности, песчаной пустыни, открытой лавы, россыпи блокирующих валунов. Панцирь — только гладкий снег/кайма, без этих каменных модулей. Не использовать человеческие следы и автомобильные колеи.

- **C — полностью CC0:** Rock Face 01 + Mountainside + C01, при нехватке формы C06 или C02 после коррекции; T01/T05 + Snow003/N02, сугробы Terrain/локальный mesh. Не брать тёплые варианты, если холодный набор достаточен. Это один из вариантов fallback; аккаунты на других площадках также доступны по запросу пользователя.
- **D — минимальная геометрия:** существующий грейбокс как основа; 2–3 закрытых локальных mesh-клифа с неправильным силуэтом, T01/T05 + один чистый снег. Разрешается повторять и поворачивать вдоль стены, соблюдая направление напластований. Не создавать уникальную модель для каждого метра.

### 5.7. Алгоритм импорта, чтобы большая база не расходовала кредиты

1. Проверить локальные Assets один раз, включая уже импортированные модели, лицензии и материалы. Выбрать семейство A/B/C/D и открыть только нужный раздел каталога. На старте 1 крупный модуль, 1 средний, 1 заполнитель, 1 большой сугроб, 1 малый сугроб, 1–2 материала породы, 1 снег. Не загружать весь каталог или полные наборы вариантов.
2. До скачивания проверить тип (mesh vs PBR), право использования, AI-отметку, цену, формат. Не оплачивать и не обходить вход. Если `No`/неясно — агент не получает ресурс, подставляет другой разрешённый бесплатный ассет. Если нет Blender/импортера glTF — не ставить новый пакет автоматически, выбрать доступный формат.
3. Для тёплых вариантов применять один пакетный профиль K2; не обрабатывать каждый экземпляр. Держать производные материалы локально в `Winter/Materials`, оригиналы отдельно. 1K дальние / 2K ближние как старт, 4K только по результатам проверки, LODGroup для больших моделей, избегать микрополигонов. Не считать glTF материал полноценной скалой.
4. Создать тестовую полосу при одинаковом освещении. Сравнить фронт и силуэт, масштаб трещин, границу снега, края и коллизии, камеру от третьего лица. Отклонить несовместимый кандидат до массового размещения. Не пытаться спасти плохо подходящую форму одной перекраской.
5. В `build-state.md` фиксировать selected_family, asset IDs, local prefab GUID, material profile, rejected IDs + причины. Для следующей зоны переиспользовать утверждённые модули, скачивать только при отсутствующей форме. Максимум два новых кандидата на одну роль, затем локальный fallback. Общий ориентир финальной карты 3–5 уникальных скальных моделей + 2–3 снеговых формы, увеличить только по фактической необходимости. Не ограничивать число экземпляров, если профилирование позволяет; не создавать сотни индивидуальных материалов.
